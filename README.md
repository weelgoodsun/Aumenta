# Aumenta

> 人本 AI 学习倍增器 · 你成长，AI 助推

Aumenta 是一个**本地优先、AI 驱动**的个人学习系统。帮你把电子书变成知识，把知识变成行动。

## 当前状态 🚧

- **MVP 开发中**
- 已完成：设计规划

## 设计原则

- **本地优先**：所有数据本地存储，AI 默认本地模型
- **隐私安全**：不上传用户数据，不提供云端服务
- **人机协作**：AI 辅助决策，人做最终判断
- **渐进学习**：从摘要到图谱到行动，逐步深入

## 主要功能（规划）

- 📚 电子书/文档等 → Markdown + 证据库
- 🧠 基础摘要生成 + 知识点分类 + 标签管理
- 🃏 间隔复习卡片 + 掌握度追踪
- 🎯 知识图谱与学习地图
- 🤖 实践任务拆解 + AI 教官
- 🔒 全本地运行，你的数据你做主
